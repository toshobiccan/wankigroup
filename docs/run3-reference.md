# Run 3 reference and adaptation

Rig preview transitions: switching Idle → Run 3 blends for 180 ms; Run 3 → Idle blends for 240 ms. Playback captures the currently displayed local bone transforms and eases toward the advancing target clip. Reversing midway starts from that visible pose. The shared actor supports opt-in `play(clipId, { transitionMs })`; existing callers retain immediate switching unless they request a transition. These are pose blends, not separate foot-planted start/stop clips.

Primary reference: [Adobe — How to create an animated run cycle](https://www.adobe.com/uk/creativecloud/animation/discover/animation-run-cycle.html), consulted 2026-09-19.

Uses the guide's side-view contact, compression, push-off and airborne poses, then repeats with opposite limbs. Same-side arms oppose the legs; arm swing reaches its largest extent during flight. Knees fold during recovery and extend before landing. The torso leans forward while the head stays comparatively steady.

Our adaptation uses a 620 ms two-step loop versus Run 2's 672 ms (8.4% faster cadence). The poses are authored as segment directions, converted to this asymmetric rig's local bone rotations by `tools/build-run3.mjs`. Front and rear limbs have different bind angles, so copying rotation deltas would not produce matching movement. The generated JSON uses the existing smooth sampler; there is no additional runtime solver.

Wrist and item bones inherit motion without animation tracks. Limb lengths and attachment positions remain fixed. Root height uses a smooth five-unit peak-to-peak bounce, avoiding the body jolts from per-frame floor clamps. The generator solves supporting thigh and shin rotations against an approximate sole guide, blends out during flight, and saves the results as ordinary animation keys. This allows the quieter body to retain landing contact without stretching the legs or adding a runtime solver. The rear elbow has an extra 0.15 radian of flex, and the rear ankle rolls toe-down through its trailing swing. Hip and chest sway are reduced, with an additional 0.035 radian forward torso lean and an upright head. The support solve blends into its reach limit and retains a small knee bend to prevent extension twitches. This stylized in-place preview does not lock feet to world movement. Run 1 and Run 2 are unchanged by this addition. Run 3 is available separately in the rig for comparison before any world-animation replacement.
