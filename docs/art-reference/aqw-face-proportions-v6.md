# AQW facial proportion study — revision 6

Study references downloaded locally under output/aqw-reference (reference-only; not shipped game assets):
- Undead Leader: https://aqwwiki.wikidot.com/undead-leader-ac ; image https://i.imgur.com/Fla5Xi7.png
- Underworld Wrangler: https://aqwwiki.wikidot.com/underworld-wrangler ; image https://i.imgur.com/iaUhKTK.png

Visual observations: rounded cranium, a short lower face, slight three-quarter turn rather than side profile, both eyes substantially visible, small internal nose mark, tapered jaw with a compact chin. Existing v5 was too long, with a protruding profile nose and narrow far eye.

Generation brief: use the references as proportional underdrawings, drawing an original face. Preserve atlas layout, grayscale recoloring, gradient irises and approved hair. Redraw the bald base with a smooth cheek silhouette; move the nose to its own head-local layer. Match pair spacing across brows/open/half/closed eyes. Fit lower-face length and feature positions as a coherent group rather than independently stretching features to avoid hair.

All parts remain attached to the head. Ears stay above hair. Shared rendering style remains base plus two cel-shadow tones and gradient irises.
