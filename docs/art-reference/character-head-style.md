# Modular character head — current implementation

The canonical head is now the user-approved original cartoon design, assets/character/head-template-approved.png. See approved-head-template.md for exact pixel registration, masks, variants and verification. Earlier face atlases and AQW studies are historical references only.

Customization: hair, linked hair/brow color, eye color, skin color, Classic/Lashes eyes, Friendly/Calm mouth. Ears, nose and head contour are fixed. Blinking and every feature stay on the existing head bone.

The approved open-eyed Friendly face uses original source pixels; changed variants use native-coordinate masks. No independent feature fitting or regeneration is used. Shared art direction continues in shared-art-style.md; future faces must be approved as complete compositions before adapting customization.
